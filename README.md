# JA Launcher

Tela inicial (launcher) para projetores e TVs Android, por **Jadilson Alves**.

## O que tem
- Relógio grande, data em português, memória livre e status da rede
- 8 cards coloridos: YouTube, Netflix, Disney+, Prime Video, Globoplay, Spotify, ESPN e TV ao vivo
- Barra de atalhos: Keystone, Imagem, HDMI, Wi-Fi, Bluetooth, Ajustes e Apps
- Tela "Todos os apps" com os ícones/banners de TV
- **Segure OK** (ou aperte Menu) em qualquer card ou atalho para escolher outro app
  (ex.: o app de Keystone do seu projetor, seu app de IPTV no card "TV ao vivo")

## Gerar o APK
Ao enviar o projeto para o GitHub, o GitHub Actions compila sozinho.
O APK aparece em **Releases → latest → JA-Launcher.apk**.

## Instalar no projetor
1. Copie o `JA-Launcher.apk` para um pendrive (ou use o app "Downloader" / "Send Files to TV").
2. Abra pelo gerenciador de arquivos do projetor e permita "fontes desconhecidas".
3. Aperte o botão **Home** do controle e escolha **JA Launcher → Sempre**.

Se o projetor não perguntar qual tela inicial usar, procure em
Configurações → Apps → Apps padrão → Tela inicial.
Para voltar ao launcher original, é só trocar por lá (ou desinstalar o JA Launcher).
